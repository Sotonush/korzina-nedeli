Ты продолжаешь разработку приложения **«Корзина недели»**. Отвечай мне только на русском.

## Что это
Мобильное приложение (PWA) для Бишкека: недельное меню и список покупок под цель (похудеть / держать вес / набрать массу / питаться здоровее), пропорции БЖУ, бюджет, семью (взрослые и дети), пожелания, аллергии, диабет и давление. Цены настоящие, из сетей **Глобус**, **Азия** (это бывший «Фрунзе», одна сеть) и **SPAR**; проверяются автоматически каждый день без ИИ.

- Сайт и установка на телефон: https://sotonush.github.io/korzina-nedeli/
- Репозиторий: https://github.com/Sotonush/korzina-nedeli (аккаунт GitHub `Sotonush`, `gh` на компьютере уже авторизован)
- Личные данные пользователя хранятся только у него в телефоне (localStorage), на сервере ничего нет.

## Как устроено
- `src/shell.html` — вёрстка и стили (цвета только токенами, светлая и тёмная тема в трёх блоках).
- `src/js/01-core.js … 06-render.js` — логика по частям, склеиваются по порядку имён (`tools/sources.js`):
  01 основа/состояние/нормы/цены · 02 подбор меню · 03 корзина/бюджет/магазины · 04 формы · 05 экраны · 06 рендер и нажатия.
- `src/data.js` — продукты (ING) и рецепты (RECIPES, 96 блюд): поля diff, yield, keeps, prep, flags (heavy/fried/sweet/salty/fatty/whiteflour), soup, side, base, needs (blender/oven), batch, season; в шагах рецептов количества в виде `[[число|ед.]]` — приложение пересчитывает их на порции.
- `src/prices.js` — стартовые цены (STORE_INFO, STORE_ITEMS; ключи `<id>@chilled` — охлаждённая курица). Генерируется `tools/research/gen.js`.
- `docs/` — собранный сайт для GitHub Pages: `index.html`, `sw.js` (офлайн), `manifest.webmanifest`, иконки, `prices.json` (живые цены).
- `tools/scraper/scrape.js` + `.github/workflows/prices.yml` — ежедневная проверка цен (cron `0 1 * * *` UTC ≈ 07:00 Бишкек, GitHub иногда запускает с опозданием). Глобус — обычный запрос к странице товара; Азия и SPAR — Glovo через Playwright. Отсеивает подозрительные цены (ниже 50% / выше 200% эталона, скачок >60% за день), не найденное оставляет со старой ценой и пометкой `stale`. `--sync` сверяет `docs/prices.json` с `src/prices.js`.

## Команды
- Тесты: `node tools/test.js`, `node tools/validate-data.js`, `node tools/tests/{menu,cart,ui,data}.test.js` (общий загрузчик `tools/tests/harness.js`). Всё должно быть «ошибок: 0» / «ALL CHECKS PASSED».
- Сборка сайта: `node tools/build-web.js` → `docs/`. Версия для claude.ai: `node tools/build.js` → `dist/`.
- Локальный просмотр: preview «korzina» (`.claude/launch.json`, http://localhost:5178, отдаёт `dist/`).
- Публикация: собрать `docs/`, `git commit` (в конце сообщения строка `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`), `git pull --rebase`, `git push`. Сайт обновляется через 1–2 минуты (проверять по версии в `docs/sw.js`).
- Сборщик цен вручную: `gh workflow run prices.yml`; результат: `gh run view <id> --log | grep Проверено`.

3. **Параллельные разработчики по областям**, у каждого свои файлы:
   - меню и калории — `01-core.js`, `02-planner.js`, `tools/tests/menu.test.js`;

   Разработчики не делают git-команды; каждый работает в своей вкладке браузера. Ты сводишь, гоняешь все тесты, публикуешь частями по мере готовности, затем снова запускаешь клиента.
4. Пиши мне коротко, что происходит; если спрашиваю «долго?» — честная оценка по фактам (время изменения файлов, тесты).

## Правила продукта (решено)
- Упаковки покупаются целиком, бюджет — на неделю. Остатки упаковок стараемся доедать в других блюдах.
- Цены только настоящие, прочитанные на сайтах; ничего не выдумывать. Магазин без онлайн-цен не показываем (Народный и Достор — нет онлайн-каталога). Нет товара в каталоге — средняя цена с пометкой «уточните в магазине».
- Свежей говядины онлайн нет ни в одной сети; охлаждённая курица есть только в Глобусе (филе 554, бедро 419, окорочка 389 сом/кг).
- Свинины в рецептах нет.
- Нельзя: `alert/confirm/prompt` (в песочнице не работают) — подтверждения только на странице; выпадающие списки — свой выбор `pickField()` (панель снизу), не системный `<select>`.
